# Deployment Configuration

This project is an Excel-based analysis and does not require a web/server deployment.

## Submission Environment
- Application: Microsoft Excel / compatible spreadsheet viewer
- Main artifact: `Simple_Profit_Analysis.xlsx`
- Repository: Public GitHub repository
- Runtime dependencies: None

## Reproduce / Run
1. Clone or download the GitHub repository.
2. Open `Simple_Profit_Analysis.xlsx` in Microsoft Excel.
3. Open the `Profit Summary` sheet to view category totals and the chart.
4. Review the `Sales Data` sheet for source rows and formulas.

This file serves as the deployment/configuration record for the spreadsheet project.
