# Rollback Evidence

Git version control is used as the rollback mechanism for this project.

## Rollback Method
Each meaningful project update should be committed separately in GitHub/Git. If a later change causes an issue, the repository can be restored to a previous working commit.

## Recommended Evidence Before Submission
After uploading the repository:
1. Make an initial commit: `Initial Simple Profit Analysis`.
2. Make a second commit after README/final review: `Add documentation and final review`.
3. Open the repository's **Commits** page and take a screenshot showing both commits.
4. Save the screenshot in the repository as `rollback_evidence.png`.

The earlier commit provides a restorable working version and demonstrates rollback capability.
